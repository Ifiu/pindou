# 拼豆图纸生成器

把图片转成 **MARD 221 色**拼豆图纸的纯前端小工具。

**一个 HTML 文件。本地双击可用，也可以直接丢到静态服务器给移动端用。**

**图片不会上传到任何地方** —— 没有上传逻辑，整个转换都在你自己的浏览器里跑。本地打开时不需要联网；放到服务器上时，「打开页面」这一步需要联网，但你的图片仍然不出设备。

## 直接用

下载 [`index.html`](./index.html)，用浏览器打开。
或者把这个文件放到静态服务器上，别人用网址访问即可 —— **手机浏览器同样能用**。

送一张图进去（**注意：这个动作叫「选图」，不是「上传」——没有任何字节离开你的设备**）：
点「选择图片」/ 拖拽到窗口 / `Ctrl+V` 粘贴 → 调参数 → 导出图纸 PNG + 色号用量清单 CSV。
（手机上：点「选择图片」从相册选；拖拽与 `Ctrl+V` 只在桌面可用，界面会按设备只显示真正能用的方式。）

手机端另有：单栏布局且预览区靠前、原图裁剪与橡皮刷可触摸拖动、双指捏合缩放、
以及针对微信 / iOS Safari 的「长按图片保存到相册」「复制 CSV」兜底。

## 特性

- **图片 → 网格图纸**：按原图比例自动定尺寸，**默认 100×100**，单边硬上限 **100 格**；
  预设 `29 / 58 / 87 / 100`（默认 100）
- **原图调整**：拖拽框选**裁剪**（8 个调整柄，带正方形预设比例）、**旋转 90° / 水平垂直翻转**
- **色域外取色**：最近邻吸附（Lab 感知空间）为基底，可叠加
  误差扩散抖动 Floyd–Steinberg / 有序抖动 Bayer / 自动减色（k-means）/ **色数上限（滑块 + 数字框双向同步，2–221）**
- **预处理**：亮度、对比度、饱和度、自动白平衡偏色校正、自动色阶
  - 三个滑杆经过**非线性压缩**（幂次 1.6），越靠近中间越细腻；**读数显示实际生效值**（滑杆 50 → 生效 33）
- **界面分「基本 / 高级」两个标签页**：基本页只放常用流程（图片输入 / 取色方式 / 图纸尺寸 / 图纸显示 / 抠图 / 导出），
  每个模块是一张圆角卡片，标题不带序号
- **线性光降采样**：避免高对比细节被压暗发灰（黑白等量降格得到 ≈#BCBCBC 而不是 #808080）
- **图纸**：每格填色 + **格内显示真色号**（`A1` / `A10` / `M15`）
  - 「显示色号」勾选框控制开关（默认勾选），与「显示坐标刻度」**并列**
  - 标签有**可读性阈值**（色号需格子 ≥ 20px），太小会自动隐藏并提示——字太小画了等于没画
  - 坐标刻度**逐格**一标：图纸四周各外扩一圈专门写数字（列号在上/下、行号在左/右，四角留空）；**这一圈只影响画面，尺寸、角标、点击都仍按原来的 m×n 算**
  - **三层线**由浅到深：细网格 `#A6AEBA`（1px）＜ 原图纸外沿 `#3E4753`（4px）＜ 最外围外框 `#0E1218`（8px）
  - **不再有 29 格板分块线**（「一块板 29 格」这个概念已整体移除）
  - 底部**色卡固定每行 8 个**、8 个正好撑满整行；块内文字是 `A2 (17)` 形态（底色就是该色号本身，文字自动取黑或白保证对比度）
  - 底部那行「图纸名 · 实际尺寸 · 共 N 颗 · 预计时长」**信息优先**：先把这四段排下，再在此前提下把字号顶到最大（放不下才逐档丢信息，最极端的两格图不画）
  - **标题在预览区上方**直接键入（默认「未命名图纸」）；**左下角标注**：`标题 · 实际 a×b 格 · 共 N 颗 · 预计 X 小时`
    （尺寸是**实际用到的包围盒**、颗数逐格现算、时长按 500 颗/小时估算；画布太窄会自动降级到只留颗数）
- **抠图**（去掉背景）：**魔术棒**删相连同色区域、**橡皮刷**按住拖动擦除（1×1/3×3/5×5）
  - 擦掉的是**真正的空格**（不计颗数、不要豆），而且**改参数后不会长回来**
  - 与「改色模式」**互斥**，任何时刻只有一个工具生效；`Ctrl+Z` 可撤销
- **预览缩放**：0.25×–4×，滚轮以光标为锚点、`+`/`−`、适应窗口；与导出分辨率完全解耦
- **手动改色 + 撤销**：色板网格选色器（搜索色号/HEX、只显示本图色号、最近用过的色），
  `Ctrl+Z` 撤销改色与锁定，锁定格在重新生成参数时不会被覆盖
- **导出**：倍数 1×/2×/4×/8×、白边收窄到约 4%、可**把用量清单画进图里**
  （网格下方一排「圆角色块 + 色号 + 颗数」小块，**按色号 `A1,A2…A9,A10…B1,B2…` 排列**、自动换行、每行居中，一张图拿出去就能开工）、
  **导出永远带色号**（与预览的「显示色号」开关故意解耦）、
  超大画布会明确拒绝而不是导出空白图
- **用量清单**：每个色号需要几颗，导出 CSV（带 BOM，Excel 直接打开不乱码）
- **成品尺寸**：按 2.6mm 小豆换算（29 格 ≈ 7.5cm，100 格 ≈ 26cm 见方）

**默认开启「自动减色 / 最多 24 色」**，这是刻意的：实测照片类图片不做减色会用到 60～200 种色号，没有谁手上有这么多拼豆。

## 色卡说明（重要）

- 内置 **MARD 221 色**（A26 / B32 / C29 / D26 / E24 / F25 / G21 / H23 / M15）。
  据查证，公开网络里**不存在「MARD 211 色」**这个档位，可核实的是 221 与扩展档 291。
- **色值不是品牌官方发布的数据**，来自公开的开源整理。且两份都叫「MARD 221」的表之间**有 77 个色号不一致**
  （例如 A5 是 `#FFE44B` 还是 `#F0D83A`）——**不存在唯一权威的 RGB 表**。
- 因此工具内置**两个谱系可切换**，并在界面上声明：**RGB 是屏幕参考值，不等于实物豆子颜色；严谨对色请以实物色卡为准。**

## 开发

```
src/ui.html       界面标记与样式
src/palette.js    MARD 221 色表（两个谱系）
src/color.js      色彩引擎：sRGB/Lab/Oklab、最近邻、FS 抖动、Bayer、k-means 减色
src/pipeline.js   图片 → 网格：线性光降采样、预处理、减色、抖动、统计
src/render.js     图纸渲染、原图对照、PNG/CSV 导出、用量清单入图
src/srcedit.js    原图裁剪、旋转、翻转
src/app.js        界面交互
build.mjs         把上面 6 个文件内联拼成单文件 HTML
tests/check.mjs   验收脚本（1428 条断言 / 8 组）
```

零依赖，只用 Node 内置模块。

```bash
node build.mjs        # 重新生成 index.html
node tests/check.mjs  # 跑验收（全过 exit 0；加 --quiet 只看分组小计）
```

改了 `src/` 之后必须重跑 `node build.mjs`，否则交付的那个 HTML 还是旧的。
